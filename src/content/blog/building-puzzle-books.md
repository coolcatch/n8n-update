I've always loved puzzles — crosswords, logic grids, word searches. So I decided to start creating my own puzzle books.

## The idea

Build a library of puzzle books that I can publish and share. Start small, learn the process, and grow from there.

## Tools I'm using

- **AI** for generating puzzle content and validating solutions
- **n8n** for automating parts of the creation workflow
- **This website** for showcasing what's available

## What's next

More books, more puzzle types, and eventually a way for people to try puzzles right on the site. Stay tuned.
