For years, my workflow was the same: install WordPress, buy Divi, drag and drop my way to a website in about 3 hours. It worked. But it always felt like I was renting someone else's house.

## What changed

I started experimenting with AI tools — specifically Claude Code — and realized I could describe what I wanted and get clean, fast code back in seconds. No plugins to update. No security patches. No $89/year license.

## The new stack

- **Astro** — builds static HTML, loads instantly
- **Tailwind CSS** — style anything without touching a CSS file
- **Claude Code** — my page builder, except it actually understands what I'm asking
- **Netlify** — push to git, site goes live

## What I lost

The drag-and-drop editor. That's honestly it.

## What I gained

Speed, ownership, zero hosting costs, and a site that loads in milliseconds instead of seconds. I'm never going back.
